# Restaurant Tipping Analysis

## Overview
This project analyses restaurant tipping behaviour using Python, pandas, SQL, and data visualisation techniques.

## Tools Used
- Python (pandas, matplotlib, seaborn)
- SQL (SQLite)
- Jupyter Notebook
- Git & GitHub

## Key Questions
- How does tipping vary by day?
- Does customer type influence tip percentage?

## Key Findings
- Tipping behaviour varies more by day than by bill size
- Weekend days tend to show higher tip percentages
- Customer type shows modest differences

## Limitations
- Customer data is simulated
- Dataset size is limited
